# Shatrubodh Project Report

## Overview
**Shatrubodh** is an AI-driven User and Entity Behavior Analytics (UEBA) platform designed to identify internal threats within an organization. It analyzes user activity logs to detect anomalous behavior that might indicate data exfiltration, privilege escalation, or other malicious activities.

## Architecture & Technology Stack
- **Frontend:** Streamlit (Python) - Provides an interactive dashboard with custom CSS for a modern "glassmorphism" aesthetic.
- **Backend Logic:** Python
- **Machine Learning:** Scikit-learn (Isolation Forest) - An unsupervised learning algorithm used for anomaly detection.
- **Data Handling:** Pandas & NumPy
- **Synthetic Data Generation:** Faker library - Used to simulate realistic user activities and inject threat scenarios.

## Core Components
1. **`app.py`**: The main entry point. Orchestrates the UI, data loading, model inference, and reporting features.
2. **`anomaly_detector.py`**: Contains the `AnomalyDetector` class which handles model training, persistence (using Joblib), and prediction.
3. **`data_generator.py`**: Simulates logs including login/logout, file operations, USB plugins, and privilege changes. It also injects specific anomaly patterns like off-hours activity and large downloads.
4. **`utils.py`**: Provides data preprocessing and feature engineering (extracting hour/day from timestamps, one-hot encoding categorical features).

## Features
- **Live Alert Feed:** Real-time display of high-risk activities with AI-generated explanations.
- **Threat Hunter:** Allows drill-down into specific user risk profiles and detailed activity history.
- **System Controls:** Interface to upload custom CSV logs and retrain the Isolation Forest model.
- **Reporting:** Filterable alert history with options to confirm threats or mark false positives, and export results as CSV.

## Detection Capabilities
Shatrubodh is currently configured to detect:
- **Off-hours Activity:** Unusual access times (e.g., late night).
- **Data Exfiltration:** Unusually large file transfers.
- **Suspicious Processes:** Execution of known malicious tools (e.g., `mimikatz.exe`).
- **Privilege Abuse:** Unauthorized access to sensitive system files.

## Future Roadmap
- Integration with real-world SIEM logs (e.g., Splunk, ELK).
- Implementation of more advanced models like LSTM for sequential behavior analysis.
- Multi-user authentication and role-based access control (RBAC).
